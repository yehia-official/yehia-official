# Security Policy

## Scope

This repository contains a personal GitHub profile README and a small
number of GitHub Actions workflows used to keep it up to date
(contribution snake, metrics dashboard, blog post sync). It does not
run a production application or process user data, so the security
surface here is intentionally small — mostly the GitHub Actions
workflows and any secrets they use.

## Supported Versions

Only the `main` branch is maintained. There are no versioned releases
of this repository.

| Branch | Supported |
|---|---|
| `main` | ✅ |
| `output` (auto-generated by the snake workflow) | ❌ — generated content only |

## Reporting a Vulnerability

If you find a security issue in one of the workflows in this
repository (for example, a workflow that could leak a secret, or an
unsafe use of `pull_request_target`), please **do not open a public
issue**.

## Secrets Used by This Repository

| Secret | Used by | Scope needed |
|---|---|---|
| `METRICS_TOKEN` | `.github/workflows/metrics.yml` | `repo`, `read:user` |
| `GITHUB_TOKEN` | `.github/workflows/snake.yml` | Automatically provided by GitHub Actions |

If you fork this repository, generate your own `METRICS_TOKEN` rather
than reusing anyone else's — see `.github/workflows/metrics.yml` for
setup notes.

## Response

As this is a personal repository, response times are best-effort. Low
-severity findings (e.g. an outdated action version) can be raised as
a normal pull request instead of a private report.
